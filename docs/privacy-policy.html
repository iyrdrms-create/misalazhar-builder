Kebijakan Privasi

Terakhir Diperbarui: 8 Mei 2026

1. Pendahuluan

Auto Form Builder ("Add-on") berkomitmen untuk melindungi privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana Add-on kami berinteraksi dengan data Anda saat Anda menggunakan layanan kami melalui Google Workspace.

2. Data yang Kami Akses

Add-on ini memerlukan izin tertentu untuk berfungsi sebagaimana mestinya:

  • Melihat dan mengelola file Google Drive Anda: Digunakan secara eksklusif untuk memungkinkan Anda memilih file Google Docs yang ingin dikonversi menjadi soal.
  • Melihat dan mengelola Google Forms Anda: Digunakan untuk menambahkan pertanyaan yang telah diproses dari Google Docs ke dalam formulir yang sedang Anda buka.

3. Penggunaan Data

Kami tidak pernah menyimpan, menyalin, atau mengirim data Anda ke server eksternal mana pun. Semua proses pengolahan data terjadi secara langsung di lingkungan Google Apps Script milik Anda. Data hanya digunakan untuk tujuan fungsional utama aplikasi, yaitu memindahkan teks dari dokumen ke formulir.

4. Penyimpanan Data

Kami tidak memiliki database eksternal. Kami tidak menyimpan informasi pribadi, konten dokumen, atau riwayat penggunaan Anda di luar sesi aktif Add-on.

5. Keamanan

Karena Add-on ini berjalan di infrastruktur Google, keamanan data Anda dijamin oleh standar keamanan Google Cloud. Kami menyarankan Anda untuk meninjau kebijakan keamanan Google untuk informasi lebih lanjut.

6. Perubahan Kebijakan

Kami dapat memperbarui kebijakan ini dari waktu ke waktu. Setiap perubahan akan diumumkan melalui pembaruan pada halaman ini.

7. Kontak

Jika Anda memiliki pertanyaan mengenai kebijakan privasi ini, Anda dapat menghubungi pengembang melalui profil Google Workspace Marketplace kami.
