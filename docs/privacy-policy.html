Privacy Policy / Kebijakan Privasi

Last Updated: May 15, 2026 / Terakhir Diperbarui: 15 Mei 2026

1. Introduction / Pendahuluan

[EN] Auto Form Builder ("Add-on") is committed to protecting your privacy. This Privacy Policy explains how our Add-on interacts with your data when you use our services through Google Workspace.

[ID] Auto Form Builder ("Add-on") berkomitmen untuk melindungi privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana Add-on kami berinteraksi dengan data Anda saat Anda menggunakan layanan kami melalui Google Workspace.

2. Data Access / Data yang Kami Akses

[EN] Auto Form Builder accesses the following Google user data to provide its core functionality:

  • Google Forms Content: We access your Google Forms via the /auth/forms scope to create new forms, add questions, and modify form settings on your behalf.
  • Google Docs Content: We read the text content of your Google Documents via the /auth/documents.readonly scope to extract questions and options for form generation.
  • Google Drive Files: We use the /auth/drive.file scope to allow you to select specific documents from your Drive using the Google Picker and read their content.
  • User Interface: We use the /auth/script.container.ui scope to display the sidebar and dialogs within your Google Workspace environment.

[ID] Auto Form Builder mengakses data pengguna Google berikut untuk menyediakan fungsi utamanya:

  • Konten Google Forms: Kami mengakses Google Forms Anda melalui cakupan /auth/forms untuk membuat formulir baru, menambahkan pertanyaan, dan mengubah pengaturan formulir atas nama Anda.
  • Konten Google Docs: Kami membaca konten teks Dokumen Google Anda melalui cakupan /auth/documents.readonly untuk mengekstrak pertanyaan dan pilihan guna pembuatan formulir.
  • File Google Drive: Kami menggunakan cakupan /auth/drive.file untuk memungkinkan Anda memilih dokumen tertentu dari Drive Anda menggunakan Google Picker dan membaca kontennya.
  • Antarmuka Pengguna: Kami menggunakan cakupan /auth/script.container.ui untuk menampilkan sidebar dan dialog di dalam lingkungan Google Workspace Anda.

3. Data Usage / Penggunaan Data

[EN] We never store your data on external servers. All processing happens locally within your Google environment.

[ID] Kami tidak pernah menyimpan data Anda di server eksternal. Semua proses terjadi secara lokal di lingkungan Google Anda.

4. Data Sharing and Disclosure / Berbagi dan Pengungkapan Data

[EN] We do not share, sell, trade, or transfer your Google user data to any third parties. Specifically, we do not use your Google user data to train, retrain, or fine-tune any Artificial Intelligence (AI) or Machine Learning (ML) models. Your data is processed locally within the Google Script environment only to perform the requested function (converting documents to forms).

[ID] Kami tidak membagikan, menjual, memperdagangkan, atau memindahkan data pengguna Google Anda ke pihak ketiga mana pun. Secara khusus, kami tidak menggunakan data pengguna Google Anda untuk melatih, melatih kembali, atau menyempurnakan model Kecerdasan Buatan (AI) atau Pembelajaran Mesin (ML) apa pun. Data Anda diproses secara lokal di lingkungan Google Script hanya untuk menjalankan fungsi yang diminta (mengonversi dokumen menjadi formulir).

5. Data Protection / Perlindungan Data

[EN] We implement industry-standard security mechanisms provided by the Google Apps Script environment to protect your sensitive data. All data transmissions are encrypted via HTTPS. We do not store your Google Docs content on any external servers.

[ID] Kami menerapkan mekanisme keamanan standar industri yang disediakan oleh lingkungan Google Apps Script untuk melindungi data sensitif Anda. Semua transmisi data dienkrpsi melalui HTTPS. Kami tidak menyimpan konten Google Docs Anda di server eksternal mana pun.

6. Data Retention and Deletion / Penyimpanan dan Penghapusan Data

[EN] We do not retain your Google user data. The content of your Google Docs is only accessed temporarily during the generation process and is immediately discarded from memory once the process is complete. No user data is stored persistently by the Add-on.

[ID] Kami tidak menyimpan data pengguna Google Anda. Konten Google Docs Anda hanya diakses sementara selama proses pembuatan dan langsung dihapus dari memori setelah proses selesai. Tidak ada data pengguna yang disimpan secara permanen oleh Add-on ini.

7. Google API Services User Data Policy / Kebijakan Data Pengguna Layanan Google API

[EN] Auto Form Builder's use and transfer of information received from Google APIs to any other app will adhere to Google API Services User Data Policy, including the Limited Use requirements. Your information is used only to provide or improve the features of our application and is not shared with any third parties or used for advertising purposes.

[ID] Penggunaan dan transfer informasi yang diterima dari Google API oleh Auto Form Builder ke aplikasi lain akan mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas. Informasi Anda hanya digunakan untuk menyediakan atau meningkatkan fitur aplikasi kami dan tidak dibagikan kepada pihak ketiga mana pun atau digunakan untuk tujuan periklanan.
